📝 Blogging Website

A simple and responsive blogging website developed as part of a society recruitment project. The project focuses on creating a clean interface where users can explore and read blog posts through an organized and user-friendly layout.

🚀 Features
📝 Display and browse blog posts
📖 Individual blog/article sections
🔍 Easy-to-navigate user interface
📱 Responsive design for different screen sizes
🎨 Clean and simple UI
🧭 Navigation between different sections of the website
🛠️ Tech Stack
HTML5 – Structure and content
CSS3 – Styling and responsive layout
JavaScript – Basic interactivity and functionality
